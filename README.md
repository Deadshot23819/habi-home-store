# Habi & Home storefront

A responsive, client-side e-commerce website concept for a Filipino home and lifestyle shop. It is built with plain HTML, CSS, and JavaScript so it can be opened and edited directly in Visual Studio Code.

## Open the website

1. Open this `habi-home-store` folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension for a local preview.

## Included interactions

- Product category filters and price sorting
- Search across product names, categories, makers, and descriptions
- Product quick views and a favorites button
- Shopping bag with quantity controls and saved cart contents
- A sample checkout confirmation and newsletter response
- Responsive navigation for phones and smaller screens

The checkout is a front-end demonstration. It does not take payment, send orders, or store customer data on a server. Real sales require a payment/order service and the shop's actual contact and delivery details.

## Images and fonts

Product and lifestyle photos are loaded from Unsplash, and the display fonts are loaded from Google Fonts. An internet connection is needed to display those assets. The image URLs are in `script.js` and `index.html`, so they can be replaced with locally hosted files when needed. [Unsplash license](https://unsplash.com/license).
